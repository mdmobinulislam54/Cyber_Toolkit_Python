# Port Number Details

A simple Python tool that displays the service name and description of common network ports.

## Features

* Lookup common TCP/UDP port numbers
* Displays service category and description
* Useful for beginners learning networking and cybersecurity

## Supported Ports

* Web: 80, 443, 8080
* Email: 25, 110, 143, 465, 587, 993, 995
* File Transfer: 20, 21, 22, 69
* Remote Access: 23, 3389, 5900
* Network Services: 53, 67, 68, 123, 161, 162
* Databases: 1433, 1521, 3306, 5432, 6379, 27017
* File Sharing: 445

## Usage

```bash
python port.py
```

Example:

```text
Enter Port Number : 443
Service : Web
Description : HTTPS (encrypted web traffic)
```
